# 예측 모델 개선 로드맵

2026-10-11 모델 평가에 따른 개선 작업 목록. 우선순위순. 각 항목은 독립 커밋으로 구현하고
`npm run verify:model` 통과를 전제로 한다.

## 현황 (2026-10-11)

- 단일-요인 상관오차 모델: `outcome_i = m_i + s + σ_i·ε_i`, `s ~ N(0, τ²)` 전국 공통 오차
- 선거구별 승리확률은 닫힌식 `Φ(m_i/√(σ_i²+τ²))`, 의회 과반만 40,000회 시뮬레이션
- 시드 고정 PRNG + 입력 해시 run ID (`us-fc-<날짜>-<해시>`)로 완전 재현 가능

## Phase 1 — 오해를 유발하는 출력 수정

### #1 하원 435 지역구 모델 ⬅ 현재 작업 중
- **문제:** 22개 경합지를 전부 D+2.0 동일값으로 넣고 225석에서 분포를 절단 → 시뮬레이션의
  ~8%가 상한에 몰려 하원 과반확률이 위쪽으로 편향됨. 사실상 예측이 아님.
- **개선:** 435개 전 지역구를 개별 모델링.
  - `margin_i = genericBallotDemMargin + lean_i` (uniform swing from baseline)
  - `lean_i` = 지역구별 2024 대선 민주당 마진 − 전국 2024 대선 민주당 마진
  - 지역구 여론조사가 있는 곳은 σ_i 축소, 없는 곳은 기본값
  - 상한 절단 제거 → 정직한 의석 분포
- **데이터:** 지역구별 2024 대선 결과 (Daily Kos Elections / MIT Election Lab)

### #2 RCV 주 처리 (AK-SEN, ME-SEN)
- **문제:** 알래스카·메인은 결선투표제(RCV)인데 D-vs-R 이진 마진 모델을 그대로 적용.
- **개선:** RCV 전이표 기반 2순위 조정, 또는 최소한 화면에 RCV 가정 명시.

## Phase 2 — 불확실성 보정 (모델의 본업)

### #3 τ 실측 보정 + fat tail
- **완료 (2026-10-11).** τ = 3.3 (2010–2022 상원 7개 사이클의 전국 오차 SD; scripts/calibrate-tau.py).
- 방법: 선거 21일 전 상원 여론조사의 레이스별 평균 마진 vs 실제 결과 → 사이클별 전국 오차(평균)
  → 사이클 간 SD. 데이터: whyalwaysrose/midterms-forecast raw_polls.csv.gz (20,466 polls).
- Fat tail: 13개 사이클 전국 오차의 kurtosis 2.45 (정규=3.0) → fat tail 증거 없음. 정규분포 유지.
- 결과: 상원 P 57.7%→58.1%, 하원 P 96.3%→97.0%.

### #4 레이스별 σ_i
- **완료 (2026-10-11).** σ_i = √(σ_sys² + σ_poll²/n_i), σ_sys=4.24, σ_poll=5.45.
- 방법: 2010–2022 상원 223개 레이스의 (평균 오차−전국 오차)² 를 1/n에 회귀
  (scripts/calibrate-sigma.py). 구간 검증: n=1–2 rms 6.85 (모델 6.91), n=8+ rms 4.42 (모델 4.66).
- n_i는 티어 추정치 (A=8: NC/GA/TX/OH/MI, B=5: NH/IA/ME/MN, C=3: AK/KS/FL) — 일일 ingest가 정확한 값으로 교체.
- 결과: 상원 P 58.1%→56.2% (얇게 조사된 레이스의 불확실성 정직 반영).

### #5 권역 상관구조
- **완료 (2026-10-11).** 2요인 모델: outcome_i = m_i + s_nat + s_reg + σ_i·ε_i.
- τ_nat=3.1, τ_reg=1.2, σ_sys 4.24→4.1. 방법: 사이클 오차를 전국+권역으로 분해
  (scripts/calibrate-regions.py). 권역 이탈 분산 3.58에서 표집노이즈 제거.
- 선거구별 닫힌식은 그대로 (주변분포는 합만 중요). 의회 시뮬레이션만 구조 변경.
- 결과: 상원 P 56.2%→56.3%, 하원 P 97.0%→97.3% (효과는 작지만 구조적으로 정직).

## Phase 3 — 입력 개선

### #6 시간가중 평균 + 추세
- **완료 (2026-10-11).** `app/us/lib/poll-aggregation.ts` 신규: 지수 시간감쇠(반감기 21일) +
  표본크기 가중 + 가중 선형 추세 추정. 추세는 표시용, m_i는 nowcast (선거일 외삽 안 함).
- Seed를 폴 리스트 기반으로 재구성: RCP 합의(중앙 필드일 09-20 추정의 pseudo-poll) +
  최신 개별조사 6건 (NYT/Siena 5, Wedgewood 1). AK 2.3→3.6, TX 2.7→3.2, GA 8.0→8.3 등.
- 결과: 상원 P 56.3%→58.4% (신규 조사가 민주에 유리), 80% 범위 47–54→48–54.

### #7 펀더멘털 블렌딩
- **완료 (2026-10-11, v1).** 하원 현직 조정: +2.0pt를 2024 승자 정당에 가산
  (문헌 기반; 18개 크로스오버 지역구가 효과 존재 뒷받침; 2024 승자=2026 현직 가정).
- 상원 펀더멘털 블렌딩(여론조사+사전분포)은 보류 — 현재 펀더멘털(주 대선+현직)이
  후보 퀄리티를 못 잡아 (예: NC 쿠퍼가 베이스라인보다 12pt 앞서는데 사전분포로
  끌어내리면 정보 손실). #9 백테스트에서 가중치 결정 후 활성화.
- 결과: 하원 P 97.3%→96.6%, 기대 246.6→240.2석 (R이 의석을 더 많이 가져 현직 효과가 R에 유리).

### #8 상원 전 의석 모델링
- **완료 (2026-10-11).** 35석 전수: 12 경합주(여론조사) + 23 비경합주(펀더멘털).
- 비경합주 마진 = 주 2024 대선 마진 + 현직 보정(D/R ±4, 임명 ±2). σ=6.5 (판단값, #9에서 보정).
  Cook 7/1 레이팅으로 목록 확정 (D 9석: CO/DE/IL/MA/NJ/NM/OR/RI/VA, R 14석).
- safeDemSeats 43→34 (선거 대상 아닌 의석만 고정).
- 결과: 상원 P 58.4%→53.4%, 기대 50.81→50.37석 (꼬리위험 정직 반영 — "안전" 의석의 이변 확률).

## Phase 4 — 검증

### #9 백테스트 + calibration 리포트
- **완료 (2026-10-11).** `scripts/backtest.py` (npm run verify:backtest): 2010–2022 상원
  223개 레이스로 레이스별 calibration 검증.
- 결과: Brier 0.055 (base rate 0.25) — 모델에 실질 skill 있음.
  표준화 잔차 sd=0.99 (분산 보정 정확), 꼬리도 정규분포와 일치.
- 발견 1: 평균 편향 +0.26 SD — 여론조사가 민주당을 ~1.4pt 과대추정.
  → #10에서 shrinkage 보정(0.7pt 차감)으로 반영.
- 발견 2: 접전 레이스에서 mild underconfidence (예측보다 favorite이 5–15pt 더 자주 승리).
  #7-full (펀더멘털 블렌딩)의 필요성을 뒷받침.
- 한계: in-sample (파라미터도 2010–2022로 보정). Leave-one-cycle-out은 향후 과제.

### #10 여론조사 편향 보정 (평가서 반영) — **HK 결정으로 미적용**
- 외부 평가서가 지적한 "여론조사기관 편향 교정" + 백테스트(#9) 발견(D+1.34 중간선거
  평균 편향)을 검토했으나, **2026-10-11 HK 결정: 보정하지 않음.**
- 이유: 사이클별 편향이 불안정하고 (2014 +2.72, 2018 +0.35, 2022 +0.96),
  2020 이후 여론조사기관의 방법론 변경으로 2026 편향은 알 수 없음.
  고정값 보정은 judgment가 과도하다는 판단.
- 코드는 `POLL_BIAS_ADJUST = 0`으로 유지 (재검토 시 쉽게 켤 수 있음).
- 상원 P 53.4% 유지 (보정 시 46.7%까지 내려갔었음).
