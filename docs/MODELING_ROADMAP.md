# 예측 모델 개선 로드맵

2026-10-11 모델 평가에 따른 개선 작업 목록. 우선순위순. 각 항목은 독립 커밋으로 구현하고
`npm run verify:model` 통과를 전제로 한다.

## 현황 (2026-10-11)

- 단일-요인 상관오차 모델: `outcome_i = m_i + s + σ_i·ε_i`, `s ~ N(0, τ²)` 전국 공통 오차
- 선거구별 승리확률은 닫힌식 `Φ(m_i/√(σ_i²+τ²))`, 의회 과반만 40,000회 시뮬레이션
- 시드 고정 PRNG + 입력 해시 run ID (`us-fc-<날짜>-<해시>`)로 완전 재현 가능

## Phase 1 — 오해를 유발하는 출력 수정

### #1 하원 435 지역구 모델 ⬅ 현재 작업 중
- **문제:** 22개 경합지를 전부 D+2.0 동일값으로 넣고 225석에서 분포를 절단 → 시뮬레이션의
  ~8%가 상한에 몰려 하원 과반확률이 위쪽으로 편향됨. 사실상 예측이 아님.
- **개선:** 435개 전 지역구를 개별 모델링.
  - `margin_i = genericBallotDemMargin + lean_i` (uniform swing from baseline)
  - `lean_i` = 지역구별 2024 대선 민주당 마진 − 전국 2024 대선 민주당 마진
  - 지역구 여론조사가 있는 곳은 σ_i 축소, 없는 곳은 기본값
  - 상한 절단 제거 → 정직한 의석 분포
- **데이터:** 지역구별 2024 대선 결과 (Daily Kos Elections / MIT Election Lab)

### #2 RCV 주 처리 (AK-SEN, ME-SEN)
- **문제:** 알래스카·메인은 결선투표제(RCV)인데 D-vs-R 이진 마진 모델을 그대로 적용.
- **개선:** RCV 전이표 기반 2순위 조정, 또는 최소한 화면에 RCV 가정 명시.

## Phase 2 — 불확실성 보정 (모델의 본업)

### #3 τ 실측 보정 + fat tail
- **문제:** τ=3.5는 주장. 과거 사이클(2014/2018/2022) 상원 여론조사 오차의 실측값으로 보정 필요.
- **개선:** 과거 사이클 전국 오차 표준편차로 τ 추정. 여론조사 미스는 fat tail이라
  t-분포(df≈6) 옵션 추가.

### #4 레이스별 σ_i
- **문제:** σ_i=4.0 일괄. 조사 15개인 레이스와 2개인 레이스의 오차가 같을 수 없음.
- **개선:** `σ_i² = 표집오차(폴스터 가중·n 반영) + 체계오차`. 폴스터 house effect 조정.

### #5 권역 상관구조
- **문제:** 단일 전국 요인 하나면 전 레이스가 완전 동조화. τ 하나에 과반확률이 과도하게 민감.
- **개선:** 전국 요인 + 센서스 4권역 요인 2단계 구조.
  `outcome_i = m_i + s_nat + s_region[r] + σ_i·ε_i`

## Phase 3 — 입력 개선

### #6 시간가중 평균 + 추세
- **문제:** m_i가 10-01 기준 정적 평균. 최근 조사 가중, 추세선 조정 없음.
- **개선:** 시간 감쇠 가중 평균 + 선형 추세 외삽 (선거일까지).

### #7 펀더멘털 블렌딩
- **문제:** 순수 여론조사 모델은 조사 적은 레이스에서 취약.
- **개선:** 현직 여부·자금·과거 대선 득표 기반 펀더멘털과 블렌딩 (가중치는 백테스트로 결정).

### #8 상원 전 의석 모델링
- **문제:** 12개 경합주만 모델링, 나머지는 "안전"으로 고정. 이변 확률 0은 비현실적.
- **개선:** 선거 대상 전 의석을 펀더멘털 기반 마진 + 적절한 σ로 모델링.

## Phase 4 — 검증

### #9 백테스트 + calibration 리포트
- **문제:** 검증이 수학(닫힌식 일치)에만 있고, 예측 성능 검증이 없음.
- **개선:** 2018/2022 당시 여론조사로 모델을 돌려 calibration 리포트
  (70%라던 사건이 실제로 70% 일어나는지). `npm run verify:model`에 추가.
