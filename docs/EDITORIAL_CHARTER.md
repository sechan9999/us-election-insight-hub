# 편집 헌장 / Editorial Charter

US Election Insights Hub는 2026년 11월 3일 미국 중간선거를 다루는 정보 제공용 현황판입니다.

1. **비당파성.** 특정 후보나 정당을 지지하지 않습니다. 색은 정당 식별용일 뿐 우열을 뜻하지 않습니다.
2. **출처.** 화면의 모든 숫자에는 출처가 붙습니다. 여론조사 평균은 공개 집계(RealClearPolitics 등) 기준이고, 예측 확률은 run ID(입력 해시 + seed)로 재현할 수 있습니다.
3. **확률은 결과가 아닙니다.** 60% 우세 후보도 열 번 중 네 번은 집니다. "이미 정해졌다"는 표현을 쓰지 않습니다.
4. **미래 데이터 금지.** 결과 발표 전에는 확률과 불확실성 범위로만 표시합니다. 개표 결과는 선거일 개표가 시작된 뒤, 인용한 집계 기관이 발표한 범위에서만 표시합니다.
5. **가정 공개.** 모델 가정(τ, σ, 하원 기준선 등)은 화면과 코드에 라벨을 붙여 둡니다.
6. **베타.** 첫 사이클의 모델은 베타입니다. 선거 후 실제 결과로 채점한 결과를 공개합니다.

---

1. **Non-partisan.** The board supports no candidate or party. Party colors identify, they do not rank.
2. **Sourced.** Every number on screen carries a source. Polling averages come from public aggregates; probabilities are reproducible from the run ID (input hash + seed).
3. **Probabilities are not results.** A 60% favorite loses four times in ten. We never say a race is "decided" before it is called.
4. **No future data.** Before results, only probabilities and uncertainty ranges are shown. Returns appear only after counting starts, as published by the cited desk.
5. **Assumptions in the open.** Model assumptions (τ, σ, House baseline) are labeled on screen and in code.
6. **Beta.** The model is in beta for its first cycle and will be scored against actual results after the election.
