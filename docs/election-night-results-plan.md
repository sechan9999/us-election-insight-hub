# 중간선거 결과 보여주기 실행 계획 (Election Night Results Plan)

Election Day: 2026-11-03 (화). Tracker window: 11-02 ~ 11-10 (ET) — `app/us/lib/live.ts`.

## 1. 결과는 언제 나오나

- 첫 결과: 11/3 오후 6시 ET 이후 (인디애나·켄터키 일부 투표 종료). 이후 파도:
  7:00 GA·VA 등, 7:30 NC·OH·WV, 8:00 PA·MI·ME·TX 등 대파도, 9:00 AZ·CO·IA·MN·NY·WI 등,
  10:00 MT·NV·UT, 11:00 CA·OR·WA, 자정 HI, 익일 1:00 AK.
- 상원 판세는 늦게 닫히는 주에 걸린다: TX·CO 오후 9시, AK 익일 오전 1시 + 순위선택(RCV) 집계에 수일.
- 선거일 밤 결과는 비공식(unofficial)이다. 우편·잠정·해외 투표 집계에 수일이 걸리고,
  CA·AZ·NV 등 우편투표 비중이 큰 주는 늦다. 접전 경합은 수일~수주, 공식 인증은 주별 마감에 따라 수주 뒤.
  그래서 트래커 창이 11/10까지이고, 인증 후 최종 수치로 교체하는 단계가 따로 있다.
- 기존 10-12 계획과 일치: 11/2는 최종 예측이 기준선(실제 개표 데이터 없음),
  라이브 카운티 업데이트는 11/3 저녁부터, 늦은 판정까지 ~11/10 커버.

## 2. 이미 지어진 것 (10-06 ~ 10-11)

- `app/us/components/LiveTracker.tsx`: /us 페이지 패널. 창 안에서는 60초마다 피드 갱신,
  피드 15분 이상 노후 시 경고 배너. 창 전에는 일정 안내, 창 후에는 종료 안내.
- `ingest/results/`: 6개 주 자동 어댑터 (NC·GA·MN·IA·FL·AK, 공식 주 선거당국 피드),
  2026 예비선거 대조 테스트 모드, 리허설 모드, 이전 피드 폴백.
- `ingest/results/job.ts` + Cloud Run job `results-ingest` (배포됨, 10-06),
  스케줄러 `results-ingest-every-minute` (현재 PAUSED).
- `app/us/lib/election-night.ts`: 벤치마크-서프라이즈 잔여표 예측 모델 (가짜 데이터 시뮬레이터 포함).
- 출처 정책 (10-06 결정, 변경 없음): 개표 수치는 공식 주 당국만, 승자 판정은 NYT 인용만
  (NYT를 스크랩하거나 재게시하지 않음). `called`는 NYT 판정이 있을 때만 표시.

## 3. 오늘(10-30) 확인한 실태

- 테스트 모드 실행: NC·GA·IA·FL 4/6 통과 (FL은 첫 실행 타임아웃 후 재실행 통과 — 일시적 지연).
  MN·AK는 샌드박스에서 연결 자체가 안 됨(curl 000) — 사이트 고장 증거가 아니라 샌드박스 egress 문제로,
  GCP에서 도는 실제 잡으로는 확인이 필요하다.
- 배포 상태: job 존재, MODE=general, 버킷 `electoral-hub-510410-us-results`에는
  `live/results_rehearsal.json`만 있고 일반 피드는 아직 없음 (창 전이라 정상).
- GA 일반선거 slug 미설정 (10-06 이후 TODO): SOS 사이트에서 선거가 게시돼야 slug를 알 수 있다.
  slug 없으면 GA 행은 피드에 안 나온다 (수동 입력 폴백 가능).
- IA는 Cloud Run에서 차단됨 (HTTP 202 빈 본문) — 수치는 수동 입력으로만 들어간다.

## 4. 오늘 지은 것: 수동 입력(overrides) 경로

- `ingest/results/overrides.ts` (신규): `live/overrides.json` 스키마 + 병합 로직.
  - NYT 판정(`called`+`calledBy`)을 자동 행에 얹고, 어댑터 없는 경합(NH·OH·MI·TX·ME·KS)과
    IA 수치를 수동 행으로 만든다. `countSource` 없는 신규 행은 경고와 함께 건너뛴다.
  - 판정은 파일에 있는 동안만 유지된다 (파일에서 빼면 다음 패스부터 미판정으로 돌아간다).
- `run.ts` / `job.ts` / `scripts/ingest-results.ts`에 연결: 잡은 매 패스마다 버킷의
  `live/overrides.json`을 읽어 병합한다 (없으면 404 → 병합 없음).
- 테스트 완료: `tsc --noEmit` 깨끗, 테스트 모드 + 샘플 overrides로 NC 판정 병합·MI 수동 행 생성·
  잘못된 행 경고 건너뜀 확인. (테스트 피드는 mode:test라 실제 패널에 절대 안 뜬다.)
